# RVC 视频伴侣（内部版）安装说明

> 版本：v3.2.2 · 适用：macOS 12+（Apple Silicon / Intel）· 打包版免装 Python / ffmpeg
> 源码版（本仓库直接跑）额外需：Python 3.10+、ffmpeg/ffprobe（brew install ffmpeg）、pynput（全局热键，`python3 -m pip install pynput`；缺失时仅热键失效，服务器其余功能正常）

> 本文面向**维护者/管理员**。终端用户请看 [README.md](README.md)。

一个把视频播放器嵌进阅读页面的 Chrome 扩展：**左边看文章，右边看视频**，支持
MKV/MOV 实时转码播放、无框模式、倍速（0.25×–3×）、键盘 A/S/D 控制。

内部版由两个组件组成：**本地服务器 .app**（转码引擎）+ **Chrome 扩展**（播放器界面，以「加载已解压」方式安装）。

---

## 三步安装（总共 2 分钟）

### 第 0 步：清除隔离标记（首次建议，只需一次）

从浏览器下载的文件会被 macOS 标记为「隔离」，直接双击 .app 会提示「无法验证开发者」——右键点它 → 打开 → 仍要打开即可（新构建 ad-hoc 签名可绕过，不再是「已损坏」死路）。想跳过这步弹窗就执行下面命令：

打开「终端」app，执行（路径按实际解压位置调整）：

```bash
xattr -cr ~/Downloads/RVC视频伴侣/RVC视频伴侣.app
```

### 第 1 步：启动本地服务器

1. 双击 `RVC视频伴侣.app`
2. 首次打开如果提示"无法打开"，**右键点它 → 打开**，确认一次即可（以后双击直接开）
3. **双击后不会出现任何窗口**，服务器在后台运行，这是正常的
   - 验证启动成功：浏览器打开 `http://127.0.0.1:8765`，能看到文件列表即可
   - 重复双击没有副作用（自动检测已在运行的实例并退出）
   - 停止方法：活动监视器搜索 `rvc-server` 结束，或终端跑 `lsof -ti:8765 | xargs kill`
4. **首次使用需授权输入监控**（macOS 安全机制，用于全局热键）：
   - 系统设置 → 隐私与安全性 → **输入监控** → 勾选 `RVC视频伴侣`
   - 不授权：**仅全局热键（S/A/D）失效**，服务器本身正常运行，浏览/播放等其余功能不受影响
   - 注意：**每次更新 .app 后需重新勾选输入监控**（系统按二进制签名记账）

### 第 2 步：安装扩展

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角 **开发者模式** 开关
3. 点左上角 **「加载已解压的扩展程序」** → 选 `reader-video-companion/` 文件夹
4. 扩展列表出现「RVC 视频伴侣」即装好

> .crx 拖拽侧载已被 Chrome 117+ 限制，不再作为主路径（见「给管理员的打包命令」备注）。

### 第 3 步：开始使用

1. 打开 `https://aim-read.top`（Reader 英语阅读助手）
2. 点浏览器右上角扩展栏里的 **RVC 视频伴侣图标**
3. 播放器出现在页面右侧，点"加载视频"选择 ~/Downloads 里的视频即可

> 之后每次使用：先双击 .app 启服务器，再打开 aim-read.top 点图标。

## 常用操作

| 操作 | 方法 |
|---|---|
| 播放 / 暂停 | 点播放按钮，或按 `S`（鼠标在页面任意位置都行） |
| 后退 / 前进 1 秒 | `A` / `D` |
| 无框模式 | 标题栏第二个按钮（方框图标），视频嵌进正文、鼠标悬停底部出现进度条 |
| 倍速 | 控制条右侧 `1×` 按钮，档位 + 滑杆（0.25–3） |
| 拖动播放器 | 按住标题栏拖动；无框模式按住视频本体拖动 |
| 关闭播放器 | 标题栏 ✕ |

## 常见问题

**Q：双击 .app 提示「无法验证开发者」？**
macOS 对未公证 app 的正常提示。右键点它 → 打开 → 仍要打开即可；想以后直接双击就做第 0 步 `xattr -cr`。（v3.2.2 新构建已修复旧的「已损坏，无法打开」死路）

**Q：提示"服务器未启动"？**
(1) 浏览器打开 `http://127.0.0.1:8765` 看是否有文件列表；(2) 没有的话重新双击 .app；(3) 仍不行看活动监视器里 `rvc-server` 进程是否存在。

**Q：全局热键 S/A/D 没反应？**
检查 系统设置 → 隐私与安全性 → 输入监控 是否勾选了 RVC视频伴侣（更新 .app 后需重新勾选）。页面内点击播放不受影响。

**Q：点视频不播放？**
这是"加载但暂停"设计：刷新页面后视频已就绪但需手动点一下（防止突然出声）。
点视频中央的"点击播放视频"即可。

**Q：想在别的网站用？**
内部版只支持 aim-read.top。上架版（轨道 B）已于 2026-07-31 废弃，暂无其他站点方案。

## 升级

| 组件 | 升级方法 |
|---|---|
| 服务器 .app | 退出旧版（活动监视器结束 `rvc-server`，或终端 `lsof -ti:8765 | xargs kill`）→ 删旧 .app → 放新 .app → 重新勾选输入监控权限 |
| 扩展 | chrome://extensions 里删掉旧扩展 → 重新「加载已解压」指向新的 `reader-video-companion/`（固定目录等设置会保留在浏览器里） |

## 给管理员的打包命令

```bash
# 1. 打 .app（产物：stream-server/packaging/dist/RVC视频伴侣.app，约 57MB）
#    版本号自动从 reader-video-companion/manifest.json 注入 Info.plist
bash stream-server/packaging/build.sh

# 2. 打分发包（产物：packaging/dist/RVC视频伴侣.zip，约 25MB，含 .app + 扩展 + 安装说明）
#    安装说明版本号自动注入，已删除 .command（统一用终端 xattr 一行清隔离）
bash packaging/make-distro.sh

# 3. [已弃用] 打 .crx（Chrome 117+ 限制侧载，不再作为分发主路径；仅供特殊场景参考）
bash packaging/build-crx.sh
```

> 版本号唯一源 = `reader-video-companion/manifest.json` 的 `version` 字段（ADR-001）。
> build.sh / make-distro.sh 会在构建期自动读取注入，改版本只需改这一处。

隐私说明：所有视频只在你的电脑本地处理，服务器只监听 127.0.0.1，不联网、不上传任何数据。
